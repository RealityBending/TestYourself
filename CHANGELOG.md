# Changelog

## 1.0.0 — 23 October 2026

The first release, and the version the MINT follow-up study runs on (`?project=mint`, ethics reference
2026-2817-3620). Everything saved before it is a pilot, and `data/collected/preprocess.R` leaves it out
unless asked (`--include-pilot`).

- **How You Think (the ICAR-16) is out**, on both timelines: too long for where it sits, to be thought again. Its
  block, figure and pictures are kept, so a run of this version asks one optional level fewer than the ethics
  application lists.
- **The consent form carries the ethics reference**, and fits the run: a link naming no project walks `all`, which
  has no core and no interim, so its runs are told they can stop after any level and are debriefed at the foot of
  the form.
- **The old link words are gone**: `?battery=` and `?b=` (now `?project=` and `?p=`) and `?sub=` (now `?pid=`)
  are no longer read, so a pilot's link carrying them walks `all` under a code of the app's own.
